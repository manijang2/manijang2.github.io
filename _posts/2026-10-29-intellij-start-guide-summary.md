IntelliJ IDEA는 코드 편집기뿐 아니라 프로젝트 구성, 검색, 리팩터링, 디버깅, 버전 관리 기능을 한곳에서 제공하는 통합 개발 환경이다.

아래에는 Mac 단축키를 정리한다. 키맵 설정에 따라 단축키가 다를 수 있으며, 표기가 분명하지 않은 기능은 메뉴나 Action 검색으로 찾을 수 있다.

## Toolbox와 프로젝트 생성

Toolbox는 IntelliJ IDEA를 비롯한 JetBrains 제품을 설치하고 관리할 때 사용하는 도구다. 프로젝트를 만든 다음에는 메인 메서드를 생성하고 실행하는 기본 흐름을 익힌다.

디렉터리, 패키지, 클래스처럼 프로젝트에 필요한 항목은 새 항목 메뉴에서 생성한다.

- 새 항목 생성: `Command + N`
- Java 메인 메서드 템플릿: `psvm` 입력 후 자동 완성
- `System.out.println()` 템플릿: `sout` 입력 후 자동 완성
- 현재 위치의 실행 구성 실행: `Control + R`
- 이전 실행 구성 다시 실행: `Control + Shift + R`

현재 위치의 실행 구성이나 이전 실행 구성을 실행할 수 있다.

## 코드 줄 편집

편집기에서 줄을 복제하거나 삭제하고, 여러 줄을 하나로 합치거나 줄의 위치를 옮길 수 있다. 코드의 일부를 이동할 때는 단어, 구문, 줄, 요소 단위 명령을 활용할 수 있다.

- 줄 복제: `Command + D`
- 줄 삭제: `Command + Backspace`
- 문자열이 있는 줄 합치기: `Control + Shift + J`
- 줄 단위 이동: `Shift + Command + 위/아래`

## 코드와 문서 즉시 확인

코드를 작성하다 보면 메서드가 받는 인자, 구현 내용, API 문서를 확인해야 한다. IntelliJ IDEA에서는 별도 파일이나 창으로 이동하지 않고 편집기에서 관련 내용을 열어볼 수 있다.

- 인자 정보 보기: `Command + P`
- 구현부 보기: `Option + Space`
- 문서 보기: `F1`

## 편집기 포커스와 선택

커서를 단어 단위로 옮기거나 선택하고, 현재 줄의 시작이나 끝으로 이동할 수 있다. 줄 전체를 선택하거나 페이지 단위로 이동하는 명령도 소개한다.

- 단어 단위 이동: `Option + 왼쪽/오른쪽`
- 단어 단위 선택: `Shift + Option + 왼쪽/오른쪽`
- 줄의 처음과 끝으로 이동: `Command + 왼쪽/오른쪽`
- 줄의 처음부터 끝까지 선택: `Shift + Command + 왼쪽/오른쪽`

## 특수 키로 이동 범위 조절

가이드는 키를 반복해서 눌러 편집기에서 선택하거나 이동하는 범위를 바꾸는 방법도 다룬다. 범위를 단계적으로 확장하고, 이전·다음 위치로 이동하며, 여러 커서를 두거나 오류가 난 줄로 바로 이동할 수 있다.

- 선택 범위 확장: `Option + 위/아래`
- 이전·다음 커서 위치: `Command + [` / `Command + ]`
- 멀티 커서: `Alt`를 두 번 누른 뒤 아래 방향 키를 사용
- 오류 위치로 이동: `F2`

## 텍스트 검색과 바꾸기

검색은 현재 파일 안에서만 할 수도 있고, 프로젝트 전체를 대상으로 할 수도 있다. 검색 결과를 바꾸거나 정규표현식으로 패턴을 찾아 바꾸는 기능도 제공한다.

- 현재 파일에서 찾기: `Command + F`
- 현재 파일에서 바꾸기: `Command + R`
- 프로젝트 전체에서 찾기: `Command + Shift + F`
- 프로젝트 전체에서 바꾸기: `Command + Shift + R`
- 정규표현식 검색·바꾸기: 검색 창에서 `Regex` 옵션 선택

여러 파일에 영향을 주는 변경은 검색 범위와 결과를 확인한 다음 적용하는 편이 안전하다.

## 파일, 메서드, 기능 검색

이름을 아는 파일을 바로 열거나, 메서드와 IDE 기능을 검색할 수 있다. 최근에 열었거나 수정한 파일 목록도 확인할 수 있다.

- 파일 검색: `Shift + Command + O`
- 메서드 검색: `Option + Command + O`
- Action 검색: `Shift + Command + A`
- 최근에 연 파일: `Command + E`
- 최근에 수정한 파일: `Command + Shift + E`

Action 검색은 기능 이름을 입력해 IDE 명령을 찾는 기능이다. 단축키를 모르는 명령도 검색창에서 이름으로 찾아 실행할 수 있다.

## 자동 완성

자동 완성은 입력 중인 코드에 맞는 후보를 보여준다. 기본 완성보다 문맥을 더 고려하는 스마트 완성, 정적 메서드 완성, 생성자와 Getter·Setter 생성, 재정의 메서드 생성 기능을 소개한다.

- 스마트 완성: `Control + Shift + Space`
- 정적 메서드 완성: `Control + Space` 두 번
- 생성자·Getter·Setter 생성: `Command + N`
- 재정의 메서드 생성: `Control + I`

## Live Template

Live Template은 자주 쓰는 코드 조각을 짧은 약어로 입력하는 기능이다. 템플릿 목록을 열어 사용할 수 있는 약어를 확인하고, 필요에 따라 직접 템플릿을 추가해 반복 입력을 줄인다.

- 템플릿 목록: `Command + J`

## 리팩터링: 코드 추출

리팩터링 기능은 코드의 동작을 유지하면서 구조를 바꾸도록 돕는다. 가이드는 선택한 코드에서 변수, 파라미터, 메서드, 내부 클래스를 추출하는 방법을 설명한다.

- 변수 추출: `Command + Option + V`
- 파라미터 추출: `Command + Option + P`
- 메서드 추출: `Command + Option + M`
- 내부 클래스 추출: `F6`

코드를 먼저 선택하고 추출 명령을 실행하면 IDE가 새 이름과 위치를 지정하도록 안내한다.

## 리팩터링: 이름, 타입, import와 서식

다른 리팩터링 기능으로 이름 일괄 변경, 타입 변경, 사용하지 않는 import 정리, 코드 서식 맞추기를 다룬다. 이름 변경 기능은 관련 참조도 함께 바꾸므로, 여러 파일에서 사용하는 변수나 메서드 이름을 수정할 때 유용하다.

- 이름 변경: `Shift + F6`
- import 정리: `Control + Option + O`
- 코드 서식 정리: `Command + Option + L`

import 자동 정리와 코드 서식 정리는 저장이나 편집 과정에서 자동으로 실행되도록 설정할 수도 있다.

## 디버깅

디버깅에서는 중단점을 설정하고 프로그램 실행을 멈춘 다음, 한 단계씩 실행하며 변수와 호출 흐름을 확인한다. 현재 커서 위치의 메서드를 디버그 모드로 실행하거나, 이전 실행 구성을 디버그 모드로 다시 실행할 수도 있다.

- 현재 위치의 메서드 디버그 실행: Mac `Control + Shift + D`
- 이전 실행 구성 디버그: `Control + D`
- 다음 중단점까지 실행(Resume): `Command + Option + R`
- 현재 줄 실행(Step Over): `F8`
- 호출한 메서드 안으로 이동(Step Into): `F7`
- 현재 메서드 밖으로 이동(Step Out): `Shift + F8`
- 표현식 평가: `Option + F8`

Watch는 중단된 뒤에도 특정 식이나 변수의 값을 계속 관찰하는 기능이다. 가이드에는 별도 단축키가 제시되어 있지 않다.

## IDE에서 Git 사용하기

IntelliJ IDEA의 Git 기능으로 변경 사항을 확인하고, 커밋 이력과 브랜치를 살펴보고, 커밋·푸시·풀 작업을 할 수 있다. Git 창과 Git Option Popup에서 관련 기능을 찾는다.

- Git 창 열기: `Command + 9`
- 커밋 창 열기: `Command + K`
- 푸시: `Command + Shift + K`
- 풀: Action 검색을 열고 `git pull` 실행
- 커밋 이력과 브랜치 보기: Git Option Popup에서 해당 기능 선택

## 정리

이 가이드는 IntelliJ IDEA를 처음 사용할 때 필요한 작업을 프로젝트 생성, 편집, 검색, 자동 완성, 리팩터링, 디버깅, Git과 GitHub 연동 순서로 소개한다. 처음부터 모든 단축키를 외우기보다 자주 쓰는 명령부터 적용하고, 기억나지 않는 기능은 Action 검색에서 이름으로 찾으면 된다.

IDE 메뉴에서 현재 키맵을 확인하고, 자주 쓰는 기능을 자신의 작업 방식에 맞게 익히는 것이 중요하다.
